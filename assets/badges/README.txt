Club badges
===========

Drop PNG images in this folder named by club ID and the game will show them
instead of the generated crests. Club IDs are the 2-5 letter codes used
throughout the game, e.g.:

  ARS.png    Arsenal
  MCI.png    Manchester City
  RMA.png    Real Madrid
  BAR.png    FC Barcelona
  INT.png    Inter Milan
  ACM.png    AC Milan
  BAY.png    Bayern Munich
  PSG.png    Paris Saint-Germain
  AJA2.png   Ajax
  BEN.png    Benfica
  GAL.png    Galatasaray
  CEL2.png   Celtic
  HIL.png    Al-Hilal

Full list of IDs: see js/data/clubs.js (first field of each row).
If no file exists for a club, the game falls back to its generated crest.
